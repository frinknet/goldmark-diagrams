# D2

`d2` fences route straight to `terrastruct/d2`; no preprocessor runs. D2 source
is compiled as written and laid out with the pure-Go dagre engine.

## Example

````
```d2
direction: right

orders: {
  shape: sql_table
  id: int {constraint: primary_key}
}

users: {
  shape: sql_table
  id: int {constraint: primary_key}
}

orders.id -> users.id
```
````

## Layout: dagre only

D2 is compiled with `Layout = "dagre"`. The `elk` layout (and `taro`) requires
an external plugin binary, so `WithD2Layout` rejects any value other than
`"dagre"` and keeps dagre, preserving the zero-external-binary guarantee.

```go
// "elk" is ignored; dagre is kept.
md := goldmark.New(goldmark.WithExtensions(diagrams.New(
    diagrams.WithD2Layout("elk"),
)))
```

## Themes

The `theme` from `WithTheme` selects a D2 theme:

| `theme` | D2 theme |
| --- | --- |
| `auto` (default) | `NeutralDefault` light / `DarkMauve` dark |
| `light` | `NeutralDefault` light / `DarkMauve` dark |
| `dark` | `DarkMauve` for both |
| `neutral` | `NeutralGrey` light / `DarkMauve` dark |

D2 also embeds its own `<style>` palette; the normalizer rewrites those rules
onto `--diagram-*` by class role (see [Theming](../theming.md)).

## Hooks

| Element | Attributes | Classes |
| --- | --- | --- |
| shape | `data-item="<label>"`, `data-role="shape"` | `svg-shape` |
| connection | `data-item="<index>"`, `data-role="connection"` | `svg-connection` |

A shape is named by its label, read from either the shape group (tables) or the
wrapper group (flowcharts), and gets a `<title>` child. Connections keep a
positional index because D2 draws their labels in a separate element; those
hooks can go stale after an edit (tracked in [`../../BACKLOG.md`](../../BACKLOG.md)).

```html
<g class="shape svg-shape" data-item="orders" data-role="shape">
```

## Shared with DOT and PlantUML

`dot`/`graphviz` (via `DotToD2`) and most `plantuml`/`puml` forms (via
`PlantUMLToD2`) are translated to D2 and rendered here. Their `<figure>` reports
`data-lang` as the original fence language but `data-engine="d2"`.
